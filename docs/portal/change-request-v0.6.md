## 3. การประเมินผลกระทบทางเทคนิคใน 9 หัวข้อ (Technical & Engineering Impact Assessment)

### 3.1 โครงสร้างสถาปัตยกรรมระบบ (Architecture Complexity)
- **ขอบเขตการเปลี่ยนแปลง:** เพิ่มระบบ Feature Flag (`OPS-04`) แยกตามแพลตฟอร์ม (iOS/Android) และเวอร์ชันแอป เพื่อคุมการเปิด-ปิดฟีเจอร์ระหว่าง Phase 1 และ Phase 2 โดยไม่ต้องส่งแอปขึ้น Store ใหม่ และเพิ่มโมดูล `TagFeature` + `NotificationsFeature` ใน Flutter App
- **สรุปผลกระทบ:** มีผลกระทบปานกลาง — เพิ่ม Config/Flag Layer ในแอปและ API

### 3.2 กฎเกณฑ์ทางธุรกิจและลำดับขั้นตอนการทำงาน (Business Logic & State Machine)
- **ขอบเขตการเปลี่ยนแปลง:** กำหนดให้ข้อมูลจาก AI เป็นร่าง (Draft) เสมอ (`DEC-01`), แยกสิทธิ์การมองเห็นหน้าสั่งซื้อ Tag บน iOS (เปิดเว็บ) กับ Android/Web (`TAG-02`), และปิดปุ่มรับเงินบริจาคใน MVP (`DON-00`)
- **สรุปผลกระทบ:** มีผลกระทบปานกลาง — ปรับ Flow และ Condition เช็กแพลตฟอร์ม/สถานะ

### 3.3 โครงสร้างฐานข้อมูลและการจัดการข้อมูลขนาดใหญ่ (Data & ERD Complexity)
- **ขอบเขตการเปลี่ยนแปลง:** เพิ่มตาราง/ฟิลด์สำหรับ `feature_flags`, `consent_histories` (เก็บเวอร์ชัน PDPA), `tag_orders`, `cat_tags` (ผูก 1:1 กับแมว), `notification_preferences` (รวม DND 22:00–07:00) และ `audit_logs`
- **สรุปผลกระทบ:** มีผลกระทบปานกลาง — เพิ่มตารางใน Schema โดยคงโครงสร้าง Privacy Isolation เดิม

### 3.4 การเชื่อมต่อกับระบบภายนอก (Integration Complexity)
- **ขอบเขตการเปลี่ยนแปลง:** เพิ่ม Deep Link / Universal Links สำหรับเปิดเว็บ Cat ID และแจ้งเตือน, เพิ่มช่องทาง Login 4 แบบ (`AUTH-03`: เบอร์+OTP, Apple, Google, LINE), และเปิดเว็บเบราว์เซอร์ภายนอกบน iOS สำหรับสั่ง Tag (`TAG-02`)
- **สรุปผลกระทบ:** มีผลกระทบปานกลาง — ต้องตั้งค่า Apple/Google/LINE OAuth และ Universal Links

### 3.5 งานประมวลผลเบื้องหลังและการทำงานพร้อมกัน (Async & Concurrency)
- **ขอบเขตการเปลี่ยนแปลง:** เพิ่ม Background Job สำหรับแจ้งเตือนในรัศมี 3 กม. (`F-HELP-05`), ตรวจจับประกาศไม่เคลื่อนไหว 30+7 วัน (`F-HELP-06`), ส่งออกไฟล์ PDPA JSON+PDF และระบบ AI Content Moderation (`AI-13`) เข้าคิว `OPS-02`
- **สรุปผลกระทบ:** มีผลกระทบปานกลาง — เพิ่มคิวงาน Worker ตามมาตรฐานเดิม

### 3.6 ความมั่นคงปลอดภัยและการควบคุมสิทธิ์ (Security & Compliance)
- **ขอบเขตการเปลี่ยนแปลง:** บังคับใช้ PDPA-01..04 (เข้ารหัสระดับฟิลด์ AES-256, ตรวจอายุ 13–19 ปี, ประวัติความยินยอม), 2FA สำหรับ Back-office (`OPS-01`), และเช็กกติกา App Store (`STORE-01`, `STORE-02`)
- **สรุปผลกระทบ:** มีผลกระทบสูง — ยกระดับความปลอดภัยและ Compliance ให้ผ่านการรีวิว Store

### 3.7 การรองรับโหลดสูงและความต่อเนื่องของระบบ (Scalability & Reliability - SLA)
- **ขอบเขตการเปลี่ยนแปลง:** กำหนดเป้าหมายทดสอบจริง NFR-01 (< 2 วิ หน้าแรก, < 3 วิ Cat AI) และ NFR-02 (100,000 MAU / 5,000 Concurrent) พร้อมรองรับโหมดออฟไลน์ (`NFR-07`)
- **สรุปผลกระทบ:** ไม่มีผลกระทบโครงสร้างเพิ่มเติม (สอดคล้องกับแผน Caching & Scaling เดิม)

### 3.8 การ Deploy และโครงสร้างพื้นฐานคลาวด์ (Operational & Infrastructure)
- **ขอบเขตการเปลี่ยนแปลง:** เพิ่มหน้าเว็บสาธารณะ Cat ID (บน Safari/Chrome) และเว็บระบบหลังบ้าน Back-office พร้อม Endpoint ตรวจสอบ Feature Flag
- **สรุปผลกระทบ:** มีผลกระทบเล็กน้อย — ใช้ Container Topology เดิมใน Production VPC

### 3.9 ความซับซ้อนของหน้าจอและการโต้ตอบ (UI / Frontend Intricacy)
- **ขอบเขตการเปลี่ยนแปลง:** เพิ่มหน้า `/tag` (11 Sections + 3D Tag Viewer), หน้า `/notifications` (6 เส้นทางปลายทาง + ซิงก์จุดแดง), และเตรียมหน้า `/settings` (`SET-01` + `PDPA-01`) รวมถึงซ่อนปุ่มที่ย้ายไป Phase 2 ด้วย Flag
- **สรุปผลกระทบ:** มีผลกระทบปานกลาง — หน้า `/tag` และ `/notifications` พัฒนาเสร็จและล็อก Baseline แล้ว
