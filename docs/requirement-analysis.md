## 1. ตัวผลิตภัณฑ์

**แมว.live** = เว็บแอปดูแลแมวครบวงจรสำหรับเจ้าของแมวในไทย
- รูปแบบ: mobile-first web app (จอกว้างแสดงในกรอบมือถือ 390×844)
- สถานะปัจจุบัน: prototype — ข้อมูลทั้งหมดเป็น mock (`src/data` + localStorage) ยังไม่มี backend
- เทค: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, shadcn/ui, three.js (โมเดล 3D), Google Maps

## 3. หลักธุรกิจที่ต้องล็อกใน requirement

1. **Privacy เป็น core ไม่ใช่แถม** — ที่อยู่รับขนม, ตำแหน่งประกาศ (แสดงแค่ย่าน/ซอย ~500ม.), จุดสังเกตลับ, เลขบัญชี (เห็นแค่ชื่อ+ท้าย 4 ตัว), โปรไฟล์สาธารณะไม่แสดงที่อยู่/เบอร์ → ต้องมีกฎ "ฟิลด์ไหนห้ามออก API สาธารณะ" เป็นรายฟิลด์
2. **แมวหาย = หัวใจของแอป** — ผูก 4 ระบบเข้าด้วยกัน: ประกาศ ↔ ฟีด ↔ Tag tracker ↔ แชตยืนยันผู้พบ
3. **รายได้** — เลี้ยงขนม / บริจาค / ระดมทุน → ต้องมีระบบชำระเงินจริง + บัญชีผู้รับ + ประวัติการช่วยเหลือ

## 4. Entity ข้อมูลที่ backend ต้องมี (เดาจากหน้าจอ+เอกสาร)

- `users` (โปรไฟล์, ยืนยันตัวตน, ที่อยู่รับขนม·ลับ, บัญชีรับบริจาค·ลับบางส่วน)
- `cats` (หลายตัว/ผู้ใช้, สายพันธุ์, เพศ, ทำหมัน, Cat ID @MAW000xxx, รูป, ผู้ดูแลหลายคน)
- `cat_health` (สมุดสุขภาพ, วัคซีน, บันทึกอาการ, รูทีนดูแลวันนี้)
- `posts` / `comments` / `likes` / `saves` / `follows` / `reports` (เหตุผลแจ้ง)
- `announcements` (5 ประเภท + ระดมทุน + จุดสังเกตลับ + ตำแหน่งย่าน + สถานะเปิด/ปิด + link ไปโพสต์ในฟีด)
- `sightings` (เบาะแส → ส่งเจ้าของ+ทีมงาน)
- `places` (สถานที่ผูกพิกัด: คาเฟ่/คลินิก/ร้าน/รพ.สัตว์ฉุกเฉิน + เวลาเปิดปิด + รีวิว)
- `devices` (แมว.live Tag: แบต/เสียง/เชื่อมต่อ/ตำแหน่งล่าสุด) + `cat_locations` (history)
- `ai_chats` (Cat AI เซสชันผูกกับแมวตัวที่เลือก)
- `orders`/`treats`/`donations` (เลี้ยงขนม, ระดมทุน, ชำระเงิน QR)
- `messages` (แชตระหว่างผู้ใช้ — รวมแชตยืนยันผู้พบแมว)
- `social_links` (เชื่อมบัญชีแชร์ต่อไปแอปอื่น)

## 5. สิ่งที่ prototype ทำไว้ชั่วคราว → ต้องทำจริงเมื่อมี backend

| เรื่อง | ตอนนี้ | ต้องทำจริง |
|---|---|---|
| ข้อมูลทั้งหมด | mock `src/data` | API + ฐานข้อมูล |
| ข้อมูล private (ที่อยู่, ประกาศของฉัน) | localStorage | ตาราง owner-only + ห้ามส่งออก API สาธารณะ |
| อัปโหลดรูป | เลือกไฟล์เครื่อง | อัปโหลดจริง + ลบ GPS ใน EXIF |
| ขีดจำกัดไฟล์ | เช็กฝั่ง client | เช็กซ้ำฝั่ง server |
| รายงาน/เบาะแส | UI อย่างเดียว | ระบบส่งทีมงาน + แจ้งเจ้าของ |
| แชร์ไปแอปอื่น | UI อย่างเดียว | เชื่อม API จริงแต่ละแพลตฟอร์ม |
| รพ.สัตว์/เบอร์โทร | mock 02-000-xxxx | ข้อมูลจริง + คำนวณระยะทาง |
| สเปก Tag | ค่าตัวอย่าง | ยืนยันฮาร์ดแวร์จริงก่อนขาย |
| ชำระเงิน | QR ตัวอย่าง | เกตเวย์จริง |
| Auth | (เอกสารไม่กล่าว) | **ต้องถาม BA** |
