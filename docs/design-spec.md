# Design Spec — แมว.live (สำหรับ Mobile App)

> **สถานะ:** ร่างสำหรับใช้ตอนเขียนแอปจริง — **ยังไม่ใช่ baseline** (รอ BA ตอบ 35 ข้อใน `docs/questions-for-ba.md`)
> **อิงจาก:** prototype web `https://www.xn--y3cm0f.live` (www.แมว.live) + `PROJECT.md` + `docs/requirement-analysis.md`
> **เป้าหมาย:** React Native (Expo) — prototype web เป็นเพียง design reference
> **จัดทำเมื่อ:** 2026-11-09

## 1. กรอบการออกแบบ (Canvas)

| เรื่อง | สเปก |
|---|---|
| ขนาดออกแบบฐาน | **390×844 pt** (iPhone 14) — ทุกหน้าออกแบบที่ความกว้างนี้ก่อน |
| โครงหลัก | mobile-first เต็มจอ, แถบเมนูล่างคงที่ 6 แท็บ |
| นำทางในเว็บ | route → ในแอปใช้ stack/tab navigator (Expo Router แปะ route เดิมได้เกือบตรง) |
| Safe area | เว้นขอบบน (notch) และขอบล่าง (home indicator) — เว็บใช้กรอบโทรศัพท์จำลองอยู่แล้ว |

### แถบเมนูล่าง (Bottom Nav) — ใช้ร่วมทุกหน้า
`หน้าแรก · ฟีด · ใกล้ฉัน · Cat AI · ช่วยเหลือ · แมวและฉัน`
- ไอคอน + ป้ายภาษาไทย, แท็บที่ใช้งานอยู่มีพื้น `--nav-tile` (เหลืองอ่อน) + ตัวหนา
- ความสูง ~64px + safe area; ไอคอน ~24px

> โทนรวม: ครีม–เหลือง–น้ำตาล (อบอุ่น เป็นมิตร) — สีสถานะอื่น (success/info) ยังไม่มีใน token ต้องเพิ่มตอนเขียนจริง

### 2.2 ฟอนต์และตัวหนังสือ

- **ฟอนต์:** ฟอนต์ไทยหลักของแอป (โหลดเองผ่าน next/font) → fallback `"Noto Sans Thai"` → system-ui
  - ในแอป: ใช้ฟอนต์เดียวกันนี้หรือ Noto Sans Thai / IBM Plex Sans Thai เป็นตัวเลือกสำรอง
- **ขนาด:** xs `12px` · sm `14px` · base `16px` · lg `18px` (line-height ตามสเกล 1.0/1.25/1.5/1.75)
- **น้ำหนัก:** 400 normal · 500 medium · 600 semibold · 700 bold · 900 black (ใช้กับหัวข้อใหญ่)

### 2.3 รูปทรงและระยะ

- **Radius:** ฐาน `12px` (`--radius`), การ์ดใหญ่ `16px` (2xl), ปุ่ม `rounded-xl`
- **Spacing:** หน่วยฐาน `4px` (สเกล Tailwind) — padding การ์ดทั่วไป 12–16px, ระยะห่างกลุ่ม 16–24px
- **ปุ่ม:** สูง ~44–56px (touch target ≥44pt), icon button ขนาด 36–44px

## 3. คอมโพเนนต์ร่วมที่ใช้หลายหน้า

| คอมโพเนนต์ | ลักษณะ |
|---|---|
| ปุ่มหลัก (Primary) | พื้น `--btn`, ขอบ `--btn-border`, ตัวหนังสือ `--ink` ตัวหนา, เต็มความกว้างหน้า, rounded-xl |
| ปุ่มรอง | พื้นขาว/soft, ขอบ `--line` |

| แท็บแคปซูล (pill) | แถวเลื่อนซ้ายขวา, ตัวเลือก = พื้น `--soft` + ตัวหนา `--text`, ไม่เลือก = `--text-muted` |

| Disclaimer แถบ | ตัวเล็ก `--text-muted` ขีดเส้นใต้เนื้อหาที่อ่อนไหว |

## 4. Spec รายหน้า

### 4.1 `/` — หน้าแรก

- **Layout:** โลโก้แอปด้านบน → รูป hero (แมวหลายตัวนั่งรวมกัน) → headline 2 บรรทัด "สวัสดี คนรักแมว / เพราะทุกแมวมีเรื่องราวที่สำคัญ" → การ์ดทางลัด 3 ใบ (ฟีดแมว, ถาม Cat AI, ขอความช่วยเหลือ) → ส่วน "อัปเดตจากชุมชน" (การ์ดโพสต์ย่อแนวตั้ง + ปุ่มดูทั้งหมด)
- **การกระทำ:** แตะการ์ดทางลัด → ไป `/community` `/cat-ai` `/help`; แตะโพสต์ย่อ → ฟีด
- **ข้อมูล:** โพสต์ล่าสุดของชุมชน (ชื่อผู้โพสต์, เวลา, ข้อความ, รูปปกติ 1–2 ใบ, ยอดไลก์/คอมเมนต์/แชร์)
- **สถานะ:** ยังไม่มีตัวอย่าง empty — ต้องออกแบบเพิ่ม (เช่น ยังไม่มีแมว/ยังไม่มีโพสต์)
- **หมายเหตุ:** หน้าเปิดแอป (splash) มีแอนิเมชันแมววิ่งเข้าหาเจ้าของ — ในแอปออกแบบเป็น splash/intro ครั้งแรก

### 4.2 `/community` — ฟีด (สไตล์ Instagram)

- **Layout:** header โลโก้ → แท็บ `ทั้งหมด / ติดตาม / บันทึกไว้` → pill กรองหมวด (เลื่อนแนวนอน) → แถว avatar story (บัญชีที่ติดตาม) → รายการโพสต์เต็มความกว้าง
- **การ์ดโพสต์:** header (avatar, ชื่อบัญชี, ป้ายหมวด/ย่าน+ระยะทาง, ปุ่มติดตาม, เมนู ···) → รูป/วิดีโอ carousel (ตัวนับ `1/4`) → แถวปุ่ม `ถูกใจ · คอมเมนต์ · แชร์ · เซฟ` + ปุ่ม **เลี้ยงขนม** ขวาสุด → ยอดไลก์ "X และคนอื่น ๆ ถูกใจ" → แคปชัน → คอมเมนต์ตัวอย่าง + "ดูความคิดเห็นทั้ง N รายการ" → เวลา
- **เมนู ··· (action sheet):** ไม่สนใจ / ซ่อนโพสต์จากบัญชีนี้ / คัดลอกลิงก์ / รายงาน (เลือกเหตุผล) / ลบ (เฉพาะโพสต์ตัวเอง)
- **โพสต์จากประกาศแมวหาย:** มีแถบ "ประกาศแมวหาย · แจ้งเบาะแส" เด่นกว่าโพสต์ปกติ
- **การกระทำพิเศษ:** ปุ่มเลี้ยงขนม → `/treats?to=<บัญชี>`; กดเซฟ → เข้าแท็บ "บันทึกไว้"
- **สถานะ:** แท็บติดตาม/บันทึกไว้ว่าง → ต้องมี empty state ("ยังไม่ได้ติดตามใคร" / "ยังไม่มีโพสต์ที่บันทึก"); loading = skeleton การ์ด; error/offline = ต้องออกแบบเพิ่ม

#### หน้า "สร้างโพสต์" (เต็มจอ 2 ขั้น — จาก `/community`)
1. **ขั้นเลือกสื่อ:** แท็บ รูปภาพ/วิดีโอ + กริดแกลลอรี่ — รูป ≤3 รูป (แสดง 1:1, แนะนำ 1080×1080) หรือวิดีโอ 1 คลิป ≤60 วิ ≤200MB
2. **ขั้นแคปชัน:** ช่องข้อความ + ตัวเลือก "แชร์เพิ่มบน…" (บัญชีโซเชียลที่เชื่อมไว้) + ปุ่มโพสต์
- กฎเด่น: **ห้ามโฆษณา/ขายอาหารแมว** (ยกเว้นพาร์ตเนอร์) → ลิงก์ดู `/guidelines`
- Mobile: ใช้ `expo-image-picker`, เช็กขีดจำกัด client + server, ลบ GPS ใน EXIF ก่อนอัปโหลด

#### หน้า "แชร์" (เต็มจอ)
- ใช้ทั้งจากโพสต์และจากโปรไฟล์แมว — แชร์ต่อไปแอปอื่น (LINE/FB/คัดลอกลิงก์ ฯลฯ) ผ่าน native share sheet + รายการแอปที่เชื่อมบัญชี
- ตอนนี้ UI อย่างเดียว — จริงต้องเชื่อม API แต่ละแพลตฟอร์ม หรือใช้ `Share` API ของ RN

### 4.3 `/p/[id]` — หน้าโพสต์เดี่ยว (deep link)

- **Layout:** โพสต์เต็ม + คอมเมนต์ทั้งหมด + ช่องพิมพ์คอมเมนต์ — ใช้การ์ดโพสต์ชุดเดียวกับฟีด
- **ใช้กับ:** ลิงก์ที่คัดลอก/แชร์ออกไป, การ์ดประกาศ "ดูโพสต์ในฟีด"
- ⚠️ ตัวอย่าง URL จริงยังไม่เจอจากหน้าเว็บ (โพสต์ไม่มีลิงก์ตรงใน HTML) — ถือว่า route มีตาม `PROJECT.md`

### 4.4 `/nearby` — ใกล้ฉัน

- **Layout:** แผนที่เต็มจอ + แถบบนลอย (ช่องค้นหา + pill หมวด `คาเฟ่ คลินิก ร้านสัตว์เลี้ยง ประกาศใกล้ฉัน อาบน้ำตัดขน รับฝากแมว` + "ในรัศมี 3 กม.") → ปุ่มสลับ แผนที่↔รายการ
- **โหมดรายการ:** การ์ดฉุกเฉินติดบน "**ฉุกเฉิน 24 ชม.** รพ.สัตว์ปากซอย · 1.2 กม. [โทร]" → ส่วน "สถานที่ใกล้คุณ" (ชื่อ, คะแนน★(รีวิว), ระยะ, หมวด, เปิดอยู่/ปิดเวลา) → "แมวใกล้คุณ" (การ์ดประกาศแมวหาย/พบแมว + ระยะทาง + ปุ่มดูประกาศ)
- **การกระทำ:** แตะหมุด → การ์ดสถานที่ + ปุ่มนำทาง; ปุ่มโทร → `tel:`; แตะประกาศ → รายละเอียดประกาศ
- **สถานะ:** มีตัวอย่าง loading "กำลังหาตำแหน่งของคุณ…" — ต้องออกแบบเพิ่ม: ผู้ใช้ไม่ให้สิทธิ์ GPS, ไม่มีผลในรัศมี
- **Privacy:** ตำแหน่งประกาศแสดงแบบประมาณ (ย่าน/ซอย ~500 ม.) ไม่มีเลขที่บ้าน
- **Mobile:** `react-native-maps` + Google Maps API key จริง + ขอสิทธิ์ location

### 4.5 `/cat-ai` — Cat AI

- **Layout:** การ์ดแมวที่เลือกบนสุด (มะลิ · สายพันธุ์ · อายุ + ลิงก์แก้ไขโปรไฟล์แมว) → ปุ่มใหญ่ "แตะเพื่อเริ่มพูด" (voice) → ชิปคำถามแนะนำ (วัคซีนรอบถัดไป, อาเจียน ทำยังไงดี) → ช่องพิมพ์ถาม Cat AI → disclaimer "Cat AI อาจผิดพลาดได้ และไม่ใช่สัตวแพทย์ · ใช้เป็นข้อมูลเบื้องต้น"
- **ความสามารถ:** แชตถาม-ตอบ (พิมพ์+เสียง), โทรคุยสัตวแพทย์ AI, เซสชันผูกกับแมวตัวที่เลือก, บันทึกอาการลงสมุดสุขภาพได้ (ดูหัวข้อ `/my-cat/health` มีบันทึก "จาก Cat AI")
- **สถานะ:** ต้องออกแบบเพิ่ม — AI กำลังคิด (typing), เสียงไม่ชัด, ขัดข้อง/เน็ตหลุด, เลือกแมวหลายตัว
- **Mobile:** mic → `expo-av`/speech; เสียงออก TTS; streaming chat

#### `/cat-ai/face-check` — ดูสีหน้า (ตรวจใบหน้าแมว)
- **Layout:** หัวข้อ "เจ็บตรงไหน ดูจากสีหน้าได้" + อธิบายแมวซ่อนความเจ็บปวด → ลิสต์ 5 จุดที่ AI ดู (หู/ตา/ปากและจมูก/หนวด/ท่าศีรษะ) → ปุ่ม "ลองด้วยรูปตัวอย่าง" + "ถ่ายรูปหน้า<แมว>" + "เลือกจากคลังรูป"
- **การกระทำ:** ถ่ายรูป/เลือกรูป → AI วิเคราะห์ 5 จุด → ผลลัพธ์ว่าควรสังเกตอะไรต่อ (ต้องออกแบบหน้าผลเพิ่ม — prototype ไม่ได้แสดงใน fetch)
- **Mobile:** `expo-camera` + image picker; disclaimer เดียวกับ Cat AI

### 4.6 `/help` — ช่วยเหลือ

- **Layout:** แท็บ `ใกล้คุณ / ประกาศของฉัน` → pill กรองประเภทพร้อมจำนวน `แมวหาย3 พบแมว2 ขอช่วย2 รับเลี้ยง2 อุปการะ1` → การ์ดประกาศ → แถบล่างมีปุ่ม 🚨 **ฉุกเฉิน** + **+ สร้างประกาศ**
- **การ์ดประกาศ:** รูปแมว, สติกเกอร์ประเภท (แมวหาย/พบแมว/…, "ด่วน" สีแดง), ชื่อ+ลักษณะ, ย่าน+ระยะทาง, เวลาที่หาย/พบ → ปุ่ม `แจ้งเบาะแส` + `ดูรายละเอียด`
- **หมายเหตุใต้ลิสต์:** "ตำแหน่งในประกาศแสดงแบบประมาณเพื่อความปลอดภัย"
- **ประกาศระดมทุน:** อยู่ในชุดเดียวกัน (ตาม `PROJECT.md`)
- **แท็บประกาศของฉัน:** เฉพาะของเรา + สถานะเปิด/ปิด + ลิงก์ไปโพสต์ในฟีด/ปุ่มเพิ่มลงฟีด + ปุ่ม "**พบน้องแล้ว · ปิดประกาศ**" (ปิดประกาศและถอนโพสต์ออกจากฟีดพร้อมกัน) + ลิงก์ "การช่วยเหลือของฉัน" (ประวัติบริจาค/แมวที่ช่วย)
- **สถานะ:** empty แท็บประกาศของฉัน ("ยังไม่มีประกาศ"), ไม่มีประกาศในรัศมี — ต้องออกแบบเพิ่ม

#### หน้า "ฉุกเฉิน" (เต็มจอ — เปิดจากปุ่ม 🚨)
- รายการอาการเร่งด่วนที่ต้องไป รพ.ทันที → รพ.สัตว์ 24 ชม. ใกล้สุด → ปุ่ม **โทรด่วน** (เปิดลิสต์โรงพยาบาลพร้อมปุ่มโทร + นำทาง)
- สีเด่น: ใช้ `--destructive` — ต้องกดได้เร็ว touch target ใหญ่
- Mobile: `Linking.openURL('tel:')` + นำทางผ่านแอปแผนที่

#### หน้า "แจ้งแมวหาย" (เต็มจอ — เปิดจาก + สร้างประกาศ)
1. เลือก "แมวของฉันตัวไหนหาย" → เติมรูป/ชื่อ/ลักษณะอัตโนมัติ (แก้ได้ + เลือกรูปผ่าน picker)
2. ระบุเวลาที่หาย
3. ตำแหน่ง — ดึงจุดล่าสุดจาก Tag หรือกรอกเอง → **แสดงแค่ย่าน รัศมี ~500 ม.**
4. **จุดสังเกตลับ** — ไม่แสดงในโพสต์ ใช้ถามยืนยันผู้พบ + คำเตือนเรื่องมิจฉาชีพ
5. สวิตช์ "เพิ่มลงฟีด" → สร้างโพสต์แถบแมวหายใน `/community` อัตโนมัติ

#### การแจ้งเบาะแส (จากปุ่มในการ์ดประกาศ)
- ส่งเบาะแสให้เจ้าของ+ทีมงาน — ตอนนี้ UI อย่างเดียว; พิกัดจริงของประกาศเปิดให้เฉพาะผู้พบที่ยืนยันตัวผ่านแชต

### 4.7 `/my-cat` — แมวและฉัน

- **Layout:** แถวเลือกตัว `ตัวฉัน / มะลิ / ส้มจี๊ด / ถั่วดำ / +เพิ่มแมว` → การ์ดโปรไฟล์แมว (รูปใหญ่, ชื่อ, สายพันธุ์·เพศ·ทำหมัน, `@MAW000123`, รับเลี้ยงตั้งแต่ปี) → แถวปุ่ม `สมุดสุขภาพ | Cat ID · ตามหา · แชร์ · แก้ไข` → แท็บ `รูปภาพ / ดูแลวันนี้ / สุขภาพ / ผู้ดูแล`

#### `/my-cat/tracker` — ตามหาแมว (Find My)

## 6. สถานะที่ต้องออกแบบเพิ่มในแอปจริง (prototype ยังไม่แสดง)

- **Empty:** ฟีดแท็บติดตาม/บันทึกไว้, ประกาศของฉัน, ยังไม่มีแมว, สมุดสุขภาพว่าง, ไม่มีผลค้นหา, ไม่มีประกาศในรัศมี, แชตว่าง
- **Loading:** skeleton โพสต์/การ์ด (prototype มีแค่ "กำลังหาตำแหน่ง…"), AI กำลังตอบ, อัปโหลดรูป, กำลังชำระเงิน
- **Error/Offline:** โหลดฟีดไม่ได้, แผนที่ล้ม, ส่งข้อความไม่สำเร็จ (ต้องมี retry), ชำระเงินล้มเหลว
- **Permission:** GPS ถูกปฏิเสธ, กล้อง/ไมค์/แกลลอรี่, push notification
- **กดซ้ำ:** ปุ่มจ่ายเงิน/โพสต์/สร้างประกาศต้อง disable ระหว่างส่ง
- **Edge:** แบตแท็กหมด, แท็กออฟไลน์นาน, แมวหายแต่ไม่มีแท็ก, ผู้รับขนมยังไม่ตั้งที่อยู่

| กล้อง/แกลลอรี่/ไมค์ | `expo-camera` `expo-image-picker` `expo-av` (+ ลบ EXIF ด้วย `expo-media-library`/image-manipulator) |

| โทร/นำทาง | `Linking` (`tel:`, `geo:`/maps url) |
| Push + โหมดเงียบ | `expo-notifications` + กำหนดเวลาฝั่ง server/client |
| QR | `react-native-qrcode-svg` / สแกนด้วย `expo-camera` |
| Bluetooth แท็ก (ถ้าใช้ BLE) | `react-native-ble-plx` (ต้องออกจาก Expo Go) — ⚠️ ยังไม่ยืนยันสเปกฮาร์ดแวร์ Tag |

## 8. สิ่งที่ยังเปิดไว้ / รอคำตอบ

- คำถาม BA 35 ข้อ (`docs/questions-for-ba.md`) — auth, สเปก Tag จริง, payment, moderation ฯลฯ
- `/connections` และผลลัพธ์ `/cat-ai/face-check` — ต้องจับหน้าจอจริงเพิ่ม (render ฝั่ง client)
- หน้า checkout/ชำระเงินของร้านค้า — prototype มีแค่ QR ตัวอย่าง
- หน้า public profile จาก QR Cat ID — ออกแบบเพิ่มตามกฎ privacy
- สีสถานะ success/info/warning — ยังไม่มีใน token, นิยามเพิ่มตอนทำ theme แอป
