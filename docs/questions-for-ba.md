## ต้องถาม BA เท่านั้น (ตอบเองไม่ได้ — เป็นคำตอบฝั่งธุรกิจ)

### 1. Scope เวอร์ชันแรก (v1)
1. หน้าทั้งหมดใน `PROJECT.md` คือ scope เต็มหรือไม่? มีอะไรเป็น "เร็ว ๆ นี้" ที่ตัดออกจาก v1 ได้บ้าง (เช่น เพ็ดดีกรี, ประกัน, บริการรำลึก)?
2. v1 ต้องมีภาษาอังกฤษ (EN) ทำงานจริงไหม หรือแค่เตรียมโครง i18n ไว้?
3. Mobile app เป้าหมายคือ iOS, Android, หรือทั้งคู่?

### 2. ตัวตนผู้ใช้ (เอกสารไม่ได้กล่าวถึงเลย)
4. ล็อกอินด้วยอะไร? (LINE / Google / Apple / เบอร์โทร+OTP) — ถ้าขึ้น App Store จำเป็นต้องมี Apple Sign-In ถ้ามี social login อื่น
5. ดูฟีด/ดูประกาศโดยไม่ล็อกอินได้ไหม หรือบังคับล็อกอินก่อนใช้?
6. มี role อื่นนอกจากเจ้าของแมวไหม? (admin/ทีมงานรับรายงาน, ร้านค้า/คลินิกเจ้าของสถานที่) — ถ้ามี เข้าผ่านแอปเดียวกันหรือระบบแยก?

### 3. แมว.live Tag (ฮาร์ดแวร์)
7. มีฮาร์ดแวร์จริงหรือยัง? ตัวจริงใช้เทคอะไร (GPS ในตัว / Bluetooth / crowd-find แบบ AirTag)?
8. v1 ต้องเชื่อม Tag จริงไหม หรือทำ UI + mock ข้อมูลตำแหน่งไว้ก่อน?
9. Tag ขายในแอปเลยไหม (ตะกร้า+ชำระเงิน) หรือลิงก์ออกไปช่องทางอื่น?

### 4. เงินและการชำระ
10. "เลี้ยงขนม"/ระดมทุน จ่ายผ่านช่องทางไหนจริง? (PromptPay / Omise / Stripe / อื่น ๆ) — ถ้าขายของในแอป iOS ต้องเช็กด้วยว่าเข้าข่าย In-App Purchase ของ Apple ไหม
11. เงินระดมทุนเข้าบัญชีใคร? แมว.live หักค่าธรรมเนียมไหม?
12. ผู้ใช้ที่ตั้งบัญชีรับบริจาคต้องยืนยันตัวตน (KYC) ก่อนไหม?

### 5. ข้อมูลและเนื้อหา
13. ข้อมูลสถานที่ (คลินิก/คาเฟ่/รพ.สัตว์) เอาจากไหน — seed เอง / ให้เจ้าของลงทะเบียน / ดึง Google Places?
14. รูปแมวและ assets ใน prototype เอามาใช้ต่อได้ไหม (ลิขสิทธิ์)?
15. "พาร์ตเนอร์" ที่โฆษณาอาหารแมวได้คือใคร? มีระบบ flag บัญชีพาร์ตเนอร์ไหม?

### 6. กฎหมายและการดูแลเนื้อหา
16. PDPA/เงื่อนไขการใช้งาน — ใครเป็นคนเขียน/มีฉบับร่างไหม?
17. รายงานโพสต์และเบาะแสแมวหายส่งถึงใคร — มีทีม moderation จริงไหม? ต้องทำหน้า admin ให้พวกเขาด้วยหรือเปล่า?

### 7. การทำงานร่วมกัน
18. ใครตรวจรับแต่ละหน้าจอ? (จะได้ล็อกเข้า PROTECTED_SCREENS.md ถูกคน)
19. มีกรอบเวลา/deadline ที่คาดไว้สำหรับ v1 ไหม?

## ตัดสินใจฝั่ง dev เองได้ (ไม่ต้องรอ BA — เสนอแนวทางไว้)

| เรื่อง | แนวทางที่เสนอ | เหตุ |
|---|---|---|
| เฟรมเวิร์ก mobile app | **React Native (Expo)** | ทีมได้ใช้ React/TS เหมือนเดิม, ย้าย logic จาก prototype ได้บางส่วน, รองรับ Maps/Camera/Push/GPS ครบ |
| โค้ด prototype `maew-live/` | ใช้เป็น **design reference + port logic** ไม่ copy ทั้งก้อน | RN ไม่มี DOM — UI ต้องเขียนใหม่อยู่แล้ว แต่ data model/i18n/logic ย้ายได้ |
| Backend | API + DB ใหม่ (เสนอ stack ภายหลังเมื่อ REQ เต็มมา) | ของเดิมไม่มี backend เลย |
| Cat AI ใช้โมเดลอะไร | dev เลือกเองได้ แต่ขอ budget อนุมัติจากหัวหน้า | เป็นคำถามค่าใช้จ่ายมากกว่า requirement |
| แผนที่ในแอป | react-native-maps + Google Maps | ต้องมี API key จริง (ขอจากหัวหน้า/ทีม) |
