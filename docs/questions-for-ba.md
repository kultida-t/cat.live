# คำถามถาม BA — แมว.live

> วันที่: 2026-11-09 · อิงจาก `PROJECT.md` + prototype ที่ www.แมว.live
> หมายเหตุ: ของจริงเป็น Mobile app (ไม่ใช่เว็บ) · REQ เต็มจากหัวหน้ากำลังตามมา — ลิสต์นี้เก็บเฉพาะคำถามที่ BA ตอบให้ได้เท่านั้น

## 1. Scope เวอร์ชันแรก (v1)

1. หน้าทั้งหมดใน `PROJECT.md` คือ scope เต็มหรือไม่? มีอะไรเป็น "เร็ว ๆ นี้" ที่ตัดออกจาก v1 ได้บ้าง (เช่น เพ็ดดีกรี, ประกัน, บริการรำลึก)?
2. v1 ต้องมีภาษาอังกฤษ (EN) ทำงานจริงไหม หรือแค่เตรียมโครง i18n ไว้?
3. Mobile app เป้าหมายคือ iOS, Android, หรือทั้งคู่?

## 2. ตัวตนผู้ใช้ (เอกสารไม่ได้กล่าวถึงเลย)

4. ล็อกอินด้วยอะไร? (LINE / Google / Apple / เบอร์โทร+OTP) — ถ้าขึ้น App Store และมี social login ตัวอื่น จำเป็นต้องมี Apple Sign-In ด้วย
5. ดูฟีด/ดูประกาศโดยไม่ล็อกอินได้ไหม หรือบังคับล็อกอินก่อนใช้?
6. มี role อื่นนอกจากเจ้าของแมวไหม? (admin/ทีมงานรับรายงาน, ร้านค้า/คลินิกเจ้าของสถานที่) — ถ้ามี เข้าผ่านแอปเดียวกันหรือระบบแยก?

## 3. Cat AI

7. Cat AI อยู่ใน scope v1 ไหม หรือ phase ถัดไป? (ฟีเจอร์นี้มีค่าใช้จ่าย AI ต่อเนื่อง ไม่ใช่ทำครั้งเดียวจบ)
8. รูปแบบที่อนุมัติคือแบบไหน — (ก) แชทข้อความอย่างเดียว (ข) + พูดคุยด้วยเสียง/โทรคุยสัตวแพทย์ AI (ค) + ตรวจใบหน้าแมวจากรูป `/cat-ai/face-check`? ต้นทุนสามระดับนี้ต่างกันมาก อยากให้ล็อกกับหัวหน้าก่อน
9. มีงบ/เพดานค่าบริการ AI ต่อเดือนที่ตั้งไว้ไหม? หรือมี provider ที่บริษัทใช้อยู่แล้ว (เช่น มี contract กับ OpenAI/Google อยู่)?
10. ข้อมูลแชทและรูปแมวของผู้ใช้ส่งให้บริการ AI ภายนอกได้ไหม? (เรื่อง PDPA — อาจต้องมีข้อความขอ consent)

## 4. แมว.live Tag (ฮาร์ดแวร์)

11. มีฮาร์ดแวร์จริงหรือยัง? ตัวจริงใช้เทคอะไร (GPS ในตัว / Bluetooth / crowd-find แบบ AirTag)?
12. v1 ต้องเชื่อม Tag จริงไหม หรือทำ UI + mock ข้อมูลตำแหน่งไว้ก่อน?
13. Tag ขายในแอปเลยไหม (ตะกร้า+ชำระเงิน) หรือลิงก์ออกไปช่องทางอื่น?

## 5. เงินและการชำระ

14. "เลี้ยงขนม"/ระดมทุน จ่ายผ่านช่องทางไหนจริง? (PromptPay / Omise / Stripe / อื่น ๆ) — ถ้าขายของในแอป iOS ต้องเช็กด้วยว่าเข้าข่าย In-App Purchase ของ Apple ไหม
15. เงินระดมทุนเข้าบัญชีใคร? แมว.live หักค่าธรรมเนียมไหม?
16. ผู้ใช้ที่ตั้งบัญชีรับบริจาคต้องยืนยันตัวตน (KYC) ก่อนไหม?

## 6. ข้อมูลและเนื้อหา

17. ข้อมูลสถานที่ (คลินิก/คาเฟ่/รพ.สัตว์) เอาจากไหน — seed เอง / ให้เจ้าของลงทะเบียน / ดึง Google Places?
18. รูปแมวและ assets ใน prototype เอามาใช้ต่อได้ไหม (ลิขสิทธิ์)?
19. "พาร์ตเนอร์" ที่โฆษณาอาหารแมวได้คือใคร? มีระบบ flag บัญชีพาร์ตเนอร์ไหม?
20. แผนที่ใช้ Google Maps — **ใครเป็นคนเปิด API key และผูกบัญชี billing?** (Maps SDK + Places API มีค่าใช้จ่ายเมื่อเกิน free tier ต้องมีเจ้าของ Google Cloud project ชัดเจน) หรือมี key/project ของบริษัทอยู่แล้ว?

## 7. กฎหมายและการดูแลเนื้อหา

21. PDPA/เงื่อนไขการใช้งาน — ใครเป็นคนเขียน/มีฉบับร่างไหม?
22. รายงานโพสต์และเบาะแสแมวหายส่งถึงใคร — มีทีม moderation จริงไหม? ต้องทำหน้า admin ให้พวกเขาด้วยหรือเปล่า?

27. "แชร์เพิ่มบน…" / เชื่อมบัญชีโซเชียล — ตั้งใจเชื่อมแพลตฟอร์มไหนบ้าง (Facebook / IG / LINE / TikTok)?
