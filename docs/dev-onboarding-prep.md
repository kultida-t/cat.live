> **จัดทำเมื่อ:** 2026-11-10
> **อิงจาก:** คำแนะนำเพื่อน Dev + เอกสาร `dev-roadmap.md` / `backend-architecture.md` / `env-setup.md`

## 1. Stack มาตรฐานทีม (เพื่อน Dev แนะนำ — รอยืนยันพี่คิง)

| ส่วน | เทค | หมายเหตุ |
|---|---|---|
| Git | GitLab บริษัท (`git.mrfox.store`) | เราใช้อยู่แล้ว ✅ |
| AI/Dev tool | แล้วแต่คน — พี่มาเต็ม: Devin (+ Antigravity) | ไม่กระทบโค้ดที่ส่งให้ทีม เลือกตามถนัดได้ |
| แอปมือถือ | **Expo / React Native (TypeScript)** | ต้องขึ้น App Store/Play Store จริง — เขียน React ชุดเดียวได้ทั้ง iOS+Android ตรงกับ roadmap เดิม |
| API / Service | **.NET 10** | สถาปัตยกรรม **Clean Architecture** (แยกชั้น Domain→Application→Infrastructure→API) |
| Auth | **OAuth ผ่าน Keycloak ของบริษัท** | SSO ตัวเดียวกับ UGC — ตรงมาตรฐาน U-05 Unified Identity เลย |
| Styling | **NativeWind (Tailwind บน React Native)** | syntax เดียวกับ Tailwind v4 ที่ใช้ใน prototype ✅ |

## 2. เครื่องมือช่วงต้น — อะไรควรเหมือนกันทุกคน อะไรแล้วแต่คน

**ควรเหมือนกันทุกคน (standard kit):**
- Git + GitLab บริษัท + กฎ branch เดียวกัน
- **SDK/Runtime เวอร์ชันเดียวกัน** — .NET 10 SDK, Node.js LTS (สำหรับ Next.js tooling)
- ฐานข้อมูล + โปรแกรมจัดการตัวเดียวกัน (PostgreSQL + pgAdmin — ใน `env-setup.md` แล้ว)
- Lint/format rules เดียวกัน (โค้ดหน้าตาเหมือนกัน รีวิวง่าย)
- API client ตัวเดียวกัน (Postman หรือ Bruno)
- สิทธิ์เข้าบริการกลาง: UGC, CloudImageLab, Today
- การเขียนเอกสาร/อัปโหลดขึ้น UGC ตามกติกาประเมินคะแนนใหม่ (3 หมวดบังคับ)

**แล้วแต่คนได้:** AI tool (Devin/Antigravity/Cursor), ธีมจอ, plugin IDE, เครื่องมือเสริมส่วนตัว — ขอแค่ส่งออกมาเป็นโค้ด+เอกสารมาตรฐานเดียวกัน

## 4. คำถามเอาไปถามพี่คิงในที่ประชุม

*แต่ละข้อเขียนเป็น: ถามอะไร → ทำไมต้องถาม → คำตอบที่เสนอ*

### 1. ล็อกชุดเครื่องมือ (stack) เลยไหม?
- **ถามว่า:** เอา Expo/React Native (ตัวแอป) + .NET 10 (หลังบ้าน) + Keycloak (ล็อกอิน) + NativeWind (ทำหน้าตา) เป็นมาตรฐานเลยไหม
- **ทำไมต้องถาม:** stack คือฐานรากของแอป ถ้าเปลี่ยนทีหลังแทบต้องเขียนใหม่หมด ต้องล็อกให้ทุกคนในทีมใช้ชุดเดียวกันก่อนเริ่มงาน
- **ที่เสนอ:** ล็อกชุดนี้เลย เพราะ .NET + Keycloak ตรงมาตรฐานบริษัท (U-05 Unified Identity) และ Expo คือทางที่ roadmap เดิมวางไว้อยู่แล้ว

### 2. ยืนยันใช้ Expo ตาม roadmap เดิมเลยไหม?
- **ถามว่า:** แมว.live ต้องขึ้น App Store/Play Store จริง → ต้องเป็น native app → ใช้ Expo (React Native) เลยใช่ไหม
- **ทำไมต้องถาม:** เพื่อน Dev เคยเสนอ Next.js (เว็บ) แต่ requirement คือขึ้นสโตร์จริง เลยกลับมาที่ Expo — ขอยืนยันอีกทีก่อนตั้งโครงโปรเจกต์
- **ที่เสนอ:** Expo เพราะเขียน TypeScript ชุดเดียวออกทั้ง 2 สโตร์ ใช้ความรู้ React ต่อได้ และถ้าวันหน้าอยากมีเว็บควบคู่ backend (.NET API) ชุดเดียวกันใช้ร่วมได้

### 3. ต่อ Keycloak ของบริษัทตั้งแต่แรกเลยไหม?
- **ถามว่า:** ระบบล็อกอินจะต่อเข้า Keycloak กลางของบริษัท (ล็อกอินครั้งเดียวใช้ได้ทุกระบบ ตัวเดียวกับ UGC) ตั้งแต่ตอนสร้างแอปเลย หรือทำระบบเองไปก่อน
- **ทำไมต้องถาม:** ถ้าต่อตั้งแต่แรก คำถามที่ค้างไว้ใน dev-roadmap (ทำเอง self-contained หรือผ่าน Gateway กลาง) จะตอบตัวเองทันที = ต่อเลย ไม่ต้องทำล็อกอินเองแล้วค่อยย้ายทีหลัง
- **ที่เสนอ:** ต่อเลย เพราะเป็นมาตรฐาน U-05 อยู่แล้ว และลดงานที่ต้องทำซ้ำ

### 4. พี่เลี้ยง (mentor) คือใคร?
- **ถามว่า:** ใครจะเป็นคนช่วยดูและรีวิวงานช่วงแรก
- **ทำไมต้องถาม:** เพิ่งย้ายจาก BA มาเป็น Dev ช่วงแรกต้องมีคนดักจุดพลาด โดยเฉพาะรีวิวโค้ด (PR) ก่อนรวมเข้าระบบหลัก
- **ที่เสนอ:** ขอคนถนัด .NET + Clean Architecture หรือคนในทีมระบบกลาง UNIVERZA — จะได้ถามเรื่องมาตรฐาน U-xx ไปในตัวด้วย

### 5. งานชิ้นแรกควรเป็นอะไร?
- **ถามว่า:** feature แรกที่ให้ลองทำจริงควรเป็นอะไร
- **ทำไมต้องถาม:** ชิ้นแรกควรเล็กพอทำจบได้เร็ว แต่ครบทุกชั้น (หน้าแอป → API → ฐานข้อมูล) เพื่อฝึกวงจรงานตั้งแต่ต้นจนจบ
- **ที่เสนอ:** "โปรไฟล์แมว" ทำเส้นตรงครบวงจรชิ้นเดียว (vertical slice) เพราะเป็นข้อมูลกลางที่ทุก feature อื่นใช้ต่อ และไม่แตะข้อมูลอ่อนไหวมาก

### 6. "เครื่องมือที่ต้องเหมือนกัน" ครอบคลุมถึงไหน?
- **ถามว่า:** ที่พี่คิงบอกว่าเครื่องมือช่วง 6 เดือนแรกต้องเหมือนกันทุกคน หมายถึงอะไรบ้าง — เฉพาะของที่เกี่ยวกับโค้ด หรือรวม IDE/AI tool ด้วย
- **ทำไมต้องถาม:** จะได้รู้ชัดว่าอะไรต้องติดตั้งตามมาตรฐานทีม อะไรเลือกเองตามถนัดได้
- **ที่เสนอ (คำตอบที่คาด):** เหมือนกัน = SDK/runtime, Git+GitLab, ฐานข้อมูล, กฎจัดรูปแบบโค้ด (lint/format), เครื่องมือยิง API (Postman/Bruno); แล้วแต่คน = โปรแกรมเขียนโค้ด (IDE) และ AI tool — โดย AI tool ควรเป็นแบบ subscription ไม่ใช่ API key ที่คิดเงินตามการใช้

## 5. หมายเหตุ

- คำตอบข้อ 1-3 จะทำให้ต้องแก้ `dev-roadmap.md` (ตาราง stack) และ `backend-architecture.md` — ทิศทางกลับมาที่ native (Expo) เหมือน roadmap เดิมอยู่แล้ว เหลือเปลี่ยนแค่ชื่อเทค NestJS→.NET; โครงสร้างโมดูล/ตาราง/หลักการ privacy ใช้ได้เหมือนเดิม
- **บัญชี Apple Developer + Google Play ของบริษัทมีอยู่แล้ว** ✅ — ไม่ต้องจ่ายเงิน/สมัครเพิ่ม ขอแค่สิทธิ์เข้าใช้ตอนจะเอาแอปขึ้นสโตร์
- เอกสาร `env-setup.md` ต้องเพิ่มรายการ .NET 10 SDK + เครื่องมือฝั่ง Expo (Node LTS, Expo CLI, ตัวจำลองเครื่อง iOS/Android) หลังล็อก stack
